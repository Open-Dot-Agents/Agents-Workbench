# Adapter Evidence

Each candidate adapter needs a versioned evidence record before it can
graduate from this workbench into the future conformance suite. Copy
[`ADAPTER_EVIDENCE_TEMPLATE.md`](ADAPTER_EVIDENCE_TEMPLATE.md) to a
descriptively named record (for example, `copilot-cli-1.2.3.md`) and complete
every section with observed results.

Do not treat an empty template, a projection test, or an unversioned upstream
documentation page as evidence that an adapter is supported.
