# Changelog

All notable Workbench changes are documented here.

## [1.0.0] - 2026-08-12

### Added

- Experimental checked-in MCP projections for Copilot, Codex, and OpenCode.
- Deterministic projection tests for canonical JSON, Codex TOML, and OpenCode
  JSON shapes.
- Adapter evidence template and promotion requirements.
- `task verify` for release-readiness checks that do not start native harness
  CLIs.

### Notes

- Workbench artifacts are experimental. They are not supported native adapter
  claims and must not be promoted without version-pinned black-box evidence.
